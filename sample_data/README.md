# Sample data

`portfolio-demo.json` contains 714 fictional plays across 45 days, with six fictional artists and fictional track names. It is included for demonstration and screenshot reproducibility. It is not anyone's listening history.

In the sidebar, select **Explore a fictional demo dataset** to load it. Uncheck the option to return to file uploads.

Each record contains `endTime`, `artistName`, `trackName`, and `msPlayed`. The older `spotify_data.csv` remains available separately; it is not the dataset used for the portfolio screenshots.
